==================================================
TEXT ALIGNMENT SYSTEM – SECTION-WISE ALIGNMENT REFINEMENT
==================================================

Refine the text alignment across the full ZARMS Tec website based on the content type, readability, premium design, and user experience.

Do not use one fixed alignment across the whole website.
Analyze each page section and apply the most suitable alignment pattern.

GLOBAL ALIGNMENT PRINCIPLES

Use these alignment rules site-wide:

1. CENTER ALIGN
Use center alignment for:
- hero headings
- hero subheadings
- CTA banners
- short introductory statements
- section titles where the layout is symmetrical
- trust messages
- testimonial quotes if short
- empty state or highlight statements
- closing impact statements

2. JUSTIFY ALIGN
Use justified alignment for:
- long descriptive paragraphs
- company profile text
- about page content
- service explanations
- mission / vision / journey sections
- detailed project descriptions
- portfolio intro paragraphs
- explanatory content blocks with multiple lines

3. LEFT ALIGN
Use left alignment for:
- navigation menus
- mobile menu
- dropdown submenu
- contact details
- form fields and labels
- bullet points
- FAQ items
- service lists
- card metadata
- phone / email blocks
- footer links
- small UI content
- captions and labels

IMPORTANT RESPONSIVE RULE

For desktop and tablet:
- use justify alignment for long body paragraphs where recommended

For mobile:
- do not force justify on long paragraphs
- automatically switch long justified paragraphs to left align on small screens for readability
- keep center-aligned hero and CTA text centered on mobile
- keep lists, forms, contact info, and metadata left aligned on all devices

TYPOGRAPHIC ALIGNMENT STRATEGY

In most content sections, use this pattern:
- Section heading = center or left depending on layout
- Section subtitle / intro = center for intro sections, justify for body sections
- Long body paragraphs = justify on desktop/tablet, left on mobile
- Lists and bullet points = left aligned always
- Cards = heading centered or left depending on design, content text justified only if long, otherwise left
- Buttons = centered within centered sections, left or inline within content sections

==================================================
IMPLEMENTATION RULE
==================================================

Apply text alignment intentionally by section type, not randomly.

Use this practical default pattern:
- Page heroes = center
- CTA sections = center
- Long informational sections = justify on desktop/tablet, left on mobile
- Lists, FAQs, forms, contact details, metadata = left
- Grid cards = center for titles, left for supporting details
- Project and portfolio content = mostly left, except section titles

Do not center long body paragraphs on content-heavy sections.
Do not justify menus, forms, lists, FAQs, or contact details.
Do not force justify alignment on mobile for long paragraphs.

FINAL ALIGNMENT GOAL

The final website should feel:
- premium
- structured
- readable
- visually balanced
- professional
- easy to scan
- better aligned per section purpose

Use center alignment for impact.
Use justify for formal reading sections.
Use left alignment for usability-focused content.
